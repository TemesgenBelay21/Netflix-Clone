# 🎬 Netflix Clone

A modern, responsive Netflix-inspired streaming platform built with **React, Vite, and modern CSS**.

This project recreates the core visual experience of a modern streaming service, with a strong focus on clean UI, responsive layouts, reusable React components, smooth interactions, and an engaging browsing experience.

> 🚧 This project is built for educational and portfolio purposes and is not affiliated with or endorsed by Netflix.

---

## ✨ Features

- 🎬 Modern Netflix-inspired user interface
- 📱 Fully responsive design
- 🏠 Dynamic homepage
- 🔥 Trending and popular content sections
- 🎞️ Movie and TV show browsing
- 🔍 Search functionality
- 📄 Detailed movie/show information
- ▶️ Trailer and video integration
- 🎨 Modern CSS animations and transitions
- 🧩 Reusable React components
- ⚡ Fast development and build experience with Vite
- 🌙 Dark streaming-platform aesthetic
- 📐 Responsive layouts for desktop, tablet, and mobile
